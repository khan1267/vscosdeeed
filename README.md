# NovaTech - Modern Static Dummy Website

A responsive, high-performance static website built with pure HTML5, CSS3, and Vanilla JavaScript.

## 🚀 Features
- **Modern UI & Responsive Design**: Seamless experience across mobile, tablet, and desktop.
- **Dark / Light Theme Toggle**: Persistent theme choice stored in `localStorage`.
- **Interactive Sections**:
  - Hero with call-to-action & stats
  - Feature showcase cards with hover effects
  - About / value proposition section
  - Pricing comparison table
  - Working mock Contact Form with animated toast notifications
- **Zero Dependencies**: No npm packages, Webpack, or framework overhead needed.

Simply open `index.html` in your favorite web browser (e.g. double-click the file or right-click -> Open with Chrome / Edge / Firefox).
